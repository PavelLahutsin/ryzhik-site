# Лисёнок Рыжик — сайт

Статический сайт мультсериала. Страницы на русском. Сборка — обычная папка `dist/`, её можно выложить на любой статический хостинг.

Английская локаль в маршрутах зарезервирована (`src/i18n/index.ts` и `i18n` в `astro.config.mjs`), страниц на английском пока нет. Русские адреса без префикса `/ru`.

## Как запустить локально

Нужен Node.js LTS (в проекте проверялось на Node 22) и npm.

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:4321`.

### Эта ветка на Windows

Если репозиторий уже склонирован и `npm run dev` запускается:

```bat
git fetch origin
git checkout cursor/coloring-supporters-7b69
git pull
npm install
npm run dev
```

Откройте `http://localhost:4321`. Если Git пишет, что есть локальные правки, их можно отложить командой `git stash` и после просмотра вернуть `git stash pop`.

Сборка и просмотр готовых файлов:

```bash
npm run build
npm run preview
```

Перед публичным выкладом задайте адрес сайта, иначе канонические ссылки и карта сайта укажут на заглушку `https://lisenok-ryzhik.example`:

```bash
# можно положить в файл .env (образец — .env.example)
SITE=https://example.com npm run build
```

В карточках персонажей абзац под шапкой файла — это описание на сайте. Над абзацем есть HTML-комментарий, что текст можно заменить. Картинка задаётся полем `image`.

## Музыка

Альбомы лежат в `src/content/albums/*.json`. У каждого файла: `title`, `href` (куда ведёт «Слушать»), `order` и `cover` — путь к обложке. Обложки кладите в `src/assets/music/`. Страница `/music` и пункт меню «Музыка» собираются из этих файлов. Ссылка «Музыка» в `src/data/links.json` ведёт на `/music`.

## Картинки персонажей

Готовые вырезы — в `src/assets/characters/` (прозрачный webp). Поле `image` в карточке персонажа указывает на файл. Герой на главной — `ryzhik-wave.webp`. Общий кадр семьи — `family.webp`, поляна с друзьями — `src/assets/scenes/friends.webp`.

## Каталог серий

На сайте только серии из трёх плейлистов VK. Источник — `data/vk/episodes.json`. Сборку каталога делает:

```bash
npm run videos:build
```

Обновить список с VK (анонимно, три плейлиста, постранично) и не затереть уже записанные названия и `youtube_id`:

```bash
npm run videos:vk
```

Если скрипт не достаёт новый выпуск, добавьте объект в `data/vk/manual.json` и снова запустите `npm run videos:build`. Такой объект заменяет серию с тем же `vk_id` или добавляет её в конец своего плейлиста:

```json
{
  "playlist_id": 1,
  "vk_id": 456239999,
  "vk_hash": "хеш",
  "title": "Название серии",
  "duration": 180,
  "date": 1793500000,
  "youtube_id": null
}
```

`playlist_id`: 1 — все песенки, 2 — колыбельные, 3 — сонные истории. `date` — unix-время. `youtube_id` можно не указывать: тогда под плеером не будет ссылки на YouTube. Плеер включает VK по `vk_id` и `vk_hash`. Превью лежат в `public/thumbs/`.

## Как добавить персонажа

1. Положите картинку в `src/assets/characters/`, лучше webp с прозрачным фоном.
2. Создайте `src/content/characters/имя.md` по образцу соседних файлов.
3. Поля: `name`, `group` (`family` или `friends`), `order`, `role`, `image`, `imageAlt`.
4. Описание — обычный абзац под чертой `---`.

Персонаж появится на главной и на `/characters`. Мисс Ромашка в набор не входит.

## Как добавить ссылку

Откройте `src/data/links.json` и добавьте объект в массив `platforms`.

- `where: true` — блок «Где смотреть» на главной.
- `footer: true` — иконка в подвале.
- `linksPage: true` — большая кнопка на `/links`.
- `placeholder: true` — кнопка без перехода и с подписью «Ссылка появится позже». Так сейчас устроена пустая ссылка на Boosty: заполните `href`, поставьте `placeholder` в `false`, и кнопка появится на странице раскрасок.

Один и тот же список используется и в подвале, и на странице ссылок.

## Ролики

Смотрите раздел «Каталог серий» выше. Старая выгрузка YouTube в `data/youtube-audit/` больше не наполняет страницу «Смотреть». Метки «Семья» и «Друзья» по-прежнему ставятся по словам в названии. Подборки по случаю (`src/content/occasions/`) тоже смотрят на название.

## Подборки по случаю

Файлы в `src/content/occasions/`. Поле `keywords` — слова, которые ищутся в названии ролика. Это не официальный плейлист YouTube. Имя файла — это адрес, например `/watch?occasion=sleep`.

## Раскраски

Страница `/coloring` показывает образцы, а не файл для печати. PDF в репозиторий и в `public/` не кладём.

- Текст страницы — `src/content/pages/coloring.md`.
- Кнопка «Получить в VK» берёт адрес записи `vk` в `src/data/links.json` (сейчас `https://vk.ru/lisenok_ryzhik`).
- Кнопка «Получить на Boosty» появляется только когда у записи `boosty` заполнен `href`. Пока поле пустое, кнопки нет.
- Картинки образцов — `src/assets/coloring/`. Это уменьшенные листы с пометкой «образец».

## Аналитика

Яндекс Метрика не вставлена, пока не задан номер счётчика:

```bash
PUBLIC_YANDEX_METRICA_ID=12345678
```

Пустое значение — кода Метрики на страницах нет. Вебвизор в этой вставке выключен.

## Страницы

- `/` — главная
- `/watch` — каталог и плеер (iframe YouTube открывается только по нажатию, домен `youtube-nocookie.com`; рядом ссылка «Смотреть в VK» на канал)
- `/characters` — персонажи
- `/parents` — темы по названиям роликов
- `/coloring` — образцы раскрасок для поддерживающих проект, без скачивания PDF
- `/music` — альбомы
- `/links` — страница ссылок вместо Taplink
- `/privacy` — черновик политики, в поиске скрыт (`noindex`), пока в файле стоит `draft: true`
- несуществующий адрес — страница 404
